# Séances

One folder per club session: `seances/<group>/<date>/`.

```
seances/group1/2026-11-07/
  seance.md                         # the session: blocks, exercise ids, teacher notes
  figure-*.svg                      # figures used in the teacher notes
  eleves.pdf  prof.pdf              # generated by vm.py seance, kept as handed out
```

Sessions held before `vm.py seance` existed, such as `group1/2026-10-03/`, keep only
their PDFs as handed out (`eleves.pdf`, `prof.pdf`, and `tableau.pdf` for the board) and
have no `seance.md`.

A session folder can also hold a free-form student hand-out, an explainer rather than a
list of exercises, written directly in Typst because it needs a layout Markdown cannot give
(for example `polynomes.typ`, two long divisions side by side with matching colours). Build
it from the repository root:

```sh
typst compile --root . seances/group1/2026-11-07/polynomes.typ seances/group1/2026-11-07/polynomes.pdf
```

Build the two session PDFs with

```sh
python3 tools/vm.py seance seances/group1/2026-11-07
```

## seance.md

```markdown
---
title: "Chasse aux angles"
group: "Groupe 1 : 4e et 3e"
date: 2026-11-07
blocks:
  1:
    title: "Triangles égaux"
    exercises: ["0903", "0655"]
  2:
    title: "Droites remarquables du triangle"
    exercises: ["0630", "10037"]
---

## Overview
## Block 1
## Block 2
```

- Blocks are a map keyed `1`, `2`, `3`... in order. The front matter reader in `vm.py`
  cannot read a list of maps, so do not write `- title:`.
- `## Overview` (optional) and `## Block <n>` hold teaching notes in French, Markdown and
  LaTeX maths as in an exercise. They go **only** into `prof.pdf`.
- `eleves.pdf`: the statements, numbered across the whole session, under the block titles,
  laid out tight to save paper. Each heading is one line (title and difficulty dots, no
  metadata). Figures float at the top right of their statement, at most half the text width
  and without caption, with the text wrapping on their left. Parts follow on without a page
  break, and an exercise is never split across two pages.
- `prof.pdf`: a table of all exercises, the overview, then for each block its notes followed
  by every exercise with statement, hints and solution.
- No durations are printed in either PDF.
