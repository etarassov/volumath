## Statement

Résoudre les équations :

a) $2x + 7 = 11$

b) $14 - x = 5$

c) $14 - x + 3 + 3x = 5x$

d) $3(2x - 1) = 141$

e) $29 - 5(x + 1) = 4$

f) $(2(x - 3) + 7) : 5 = 15$

## Hints

1. Une équation ne change pas de solution si on ajoute le même nombre des deux côtés, ou si on multiplie les deux côtés par un même nombre non nul.
2. Dans d), e) et f), commence par défaire la dernière opération faite : divise par $3$, ou multiplie par $5$.
3. Dans c), commence par regrouper les $x$ d'un côté et les nombres seuls de l'autre. La solution n'est pas obligée d'être un nombre entier.
4. Vérifie chaque réponse en la remplaçant dans l'équation de départ.

## Solution

**a)** $2x + 7 = 11$ donne $2x = 4$, donc $x = 2$.
Vérification : $2 \times 2 + 7 = 11$.

**b)** $14 - x = 5$ donne $x = 14 - 5 = 9$.
Vérification : $14 - 9 = 5$.

**c)** À gauche, $14 - x + 3 + 3x = 17 + 2x$. L'équation devient $17 + 2x = 5x$, donc
$17 = 3x$ et

$$x = \frac{17}{3}.$$

Vérification : $17 + 2 \times \frac{17}{3} = \frac{51 + 34}{3} = \frac{85}{3}$ et
$5 \times \frac{17}{3} = \frac{85}{3}$. C'est bien la même chose.

**d)** $3(2x - 1) = 141$ donne $2x - 1 = 47$, puis $2x = 48$ et $x = 24$.
Vérification : $3 \times (48 - 1) = 3 \times 47 = 141$.

**e)** $29 - 5(x + 1) = 4$ donne $5(x + 1) = 25$, puis $x + 1 = 5$ et $x = 4$.
Vérification : $29 - 5 \times 5 = 4$.

**f)** $(2(x - 3) + 7) : 5 = 15$ donne $2(x - 3) + 7 = 75$, puis $2(x-3) = 68$,
donc $x - 3 = 34$ et $x = 37$.
Vérification : $2 \times 34 + 7 = 75$ et $75 : 5 = 15$.

Réponses : $x = 2$ ; $x = 9$ ; $x = \frac{17}{3}$ ; $x = 24$ ; $x = 4$ ; $x = 37$.
